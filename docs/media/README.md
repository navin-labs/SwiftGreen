Images the top-level README refers to. None are committed yet; the README's slots are HTML comments until they are. Record them on the reference pair, with test data only: no real contacts, numbers, messages or notification text.

| File | Size | Shows |
|---|---|---|
| `demo.gif` | 1200 × 750, under 8 MB, 15–25 s, no audio | The four steps below in one take: pair, a notification arriving on the Mac, a copy on one device pasted on the other, a file sent and opened |

| `notification-mirror.png` | 2560 × 1600 | A mirrored notification as a macOS banner with its reply field open, and the same notification in Overview |

| `file-transfer.png` | 2560 × 1600 | A transfer in progress on Overview, and the received file in Files with its size and time |

Phone screenshots, if used alongside, are 1080 × 2400 PNG.

Before committing: check each file with `scripts/check-hygiene.sh`, keep the total under 15 MB, and give every image alt text in the README that says what it shows.
